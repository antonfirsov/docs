# What do you want to see next with Machine Learning in .NET

[ML.NET](http://dot.net/ml) is an open source and cross-platform machine learning framework made for .NET developers. ML.NET provides productive tooling ([ML.NET Model Builder](https://dotnet.microsoft.com/apps/machinelearning-ai/ml-dotnet/model-builder) and ML.NET CLI) to help you easily add machine learning to your .NET apps for scenarios like sentiment analysis, price prediction, sales forecasting, recommendation, image classification, and more.

We are continuously improving the ML.NET framework and tooling, but we want to make sure we are building the right thing for you! We have created a survey to understand your machine learning needs and to make sure our roadmap aligns with your own scenario, data, and tooling needs.
