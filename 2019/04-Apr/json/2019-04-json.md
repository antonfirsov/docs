## Integration with ASP.NET Core

### Integration with ASP.NET Core Mvc
Support for System.Text.Json based input and output formatters in ASP.NET Core MVC is available as of 3.0 preview4 release. The asynchronous programming model and minimal allocation profile that the new serializer allows, works really well for web API workloads. To illustrate, here are some benchmarks comparing the performance of the formatter based on Newtonsoft.Json(that have shipped since ASP.NET Core 1.0) and System.Text.Json for varying payload sizes:

**Input formatting**

|                       Description |     RPS | CPU (%) | Memory (MB) | 
| --------------------------------- | ------- | ------- | ----------- | 
| Newtonsoft.Json - 500 bytes | 136,435 |      95 |         172 |       
| System.Text.Json - 500 bytes | 167,861 |      94 |         169 |       
| Newtonsoft.Json - 2.4 kbytes |  97,137 |      97 |         174 |      
| System.Text.Json - 2.4 kbytes | 132,026 |      96 |         169 |     
| Newtonsoft.Json - 40 kbytes |7,712 |      88 |         212 |           
| System.Text.Json - 40 kbytes |16,625 |      96 |         193 |         

**Output formatting**

|                       Description |     RPS | CPU (%) | Memory (MB) | 
| --------------------------------- | ------- | ------- | ----------- | 
|  Newtonsoft.Json - 500 bytes |   120,273 |      94 |         174 |    
| System.Text.Json - 500 bytes | 145,631 |      94 |         173 |      
|  Newtonsoft.Json - 8 Kbytes | 35,408 |      98 |         187 |        
| System.Text.Json - 8 Kbytes | 56,424 |      97 |         184 |        
|  Newtonsoft.Json - 40 Kbytes |  8,416 |      99 |         202 |       
| System.Text.Json - 40 Kbytes | 14,848 |      98 |         197 |       

For the most common payload sizes, System.Text.Json offers about 20% throughput during input and output formatting with a smaller memory footprint.

To start using these formatters in your 3.0 preview applications, simply modify your application startup to not register MVC's integration for Newtonsoft.Json based features:

```diff
public void ConfigureServices(IServiceCollection services)
{
    ...
    services.AddControllers()
-       .AddNewtonsoftJson()
    ...
}
```
 
 Options for the serializer can be configured using `MvcOptions`:
 ```C#
 services.AddControllers(options => options.SerializerOptions.WriteIndented = true) 
 ```
