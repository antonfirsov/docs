Today, we are releasing the January 2024 Security and Quality Rollup Updates for .NET Framework.  

<h3>Security</h3>
<h5>CVE-2023-36042 – .NET Framework Denial of Service Vulnerability</h5>
This security update addresses a security feature bypass vulnerability detailed in <a href="https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2023-36042" rel="nofollow">CVE 2023-36042</a>.

<h5>CVE-2023-0056 – .NET Framework Security Feature Bypass Vulnerability/h5>
This security update addresses a security feature bypass vulnerability detailed in <a href="https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2023-0056" rel="nofollow">CVE 2023-0056</a>.

<h5>CVE-2023-0057 – .NET Framework Security Feature Vulnerability</h5>
This security update addresses a elevation of privilege vulnerability  detailed in <a href="https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE2023-0057" rel="nofollow">CVE 2023-0057</a>.

<h5>CVE-2023-21312 – .NET Framework Denial of Service Vulnerability</h5>
This security update addresses a denial of service vulnerability  detailed in <a href="https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE2023-21312" rel="nofollow">CVE 2023-21312</a>.

<h5>.NET Framework Remote Code Execution Vulnerability</h5>
This security update addresses a remote code execution vulnerability to HTTP .NET remoting server channel chain.

<h3> Quality and Reliability</h3>

There are no new Quality and Reliability Improvements in this update.

<h3> <a id="user-content-getting-the-update" class="anchor" href="#getting-the-update"></a>Getting the Update</h3>

The Security and Quality Rollup is available via Windows Update, Windows Server Update Services, and Microsoft Update Catalog.  The Security Only Update is available via Windows Server Update Services and Microsoft Update Catalog.

<h5> <a id="user-content-microsoft-update-catalog" class="anchor" href="#microsoft-update-catalog"></a>Microsoft Update Catalog</h5>

You can get the update via the Microsoft Update Catalog. For Windows 10, NET Framework 4.8 updates are available via Windows Update, Windows Server Update Services, Microsoft Update Catalog. Updates for other versions of .NET Framework are part of the Windows 10 Monthly Cumulative Update.

**Note**: Customers that rely on Windows Update and Windows Server Update Services will automatically receive the .NET Framework version-specific updates. Advanced system administrators can also take use of the below direct Microsoft Update Catalog download links to .NET Framework-specific updates. Before applying these updates, please ensure that you carefully review the .NET Framework version applicability, to ensure that you only install updates on systems where they apply.

The operating system row lists a KB which will be used for update offering purposes. When the operating system KB is offered, the applicability logic will determine the specific .NET Framework update(s) will be installed. Updates for individual .NET Framework versions will be installed based on the version of .NET Framework that is already present on the device. Because of this the operating system KB is not expected to be listed as installed updates on the device. The expected update to be installed are the .NET Framework specific version updates listed in the table above.
