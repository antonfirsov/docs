Great news for C# developers! The [C# Dev Kit](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csdevkit) for Visual Studio Code experience just got significantly better! The C# extension that provides language service support for C# Dev Kit is now generally available. In June, we made this available via pre-release, and now when you install C# Dev Kit, you get everything you need for a great C# developer experience. So, if you haven't tried C# Dev Kit yet, now's the perfect time.

[cta-button align='center' text='Install C# Dev Kit' url='https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csdevkit'  color='#5c33b8']

While C# Dev Kit is still in preview, we are actively listening to your feedback. Since our initial release in June, our focus has been on ensuring a high-quality and delightful C# development experience in Visual Studio Code. We appreciate all of you who have tried this and provided us with prompt and valuable feedback. Thank you! As a result, we've been successful in resolving many issues. Key highlights of this release include:

- [.NET MAUI extension preview release](https://devblogs.microsoft.com/visualstudio/announcing-the-dotnet-maui-extension-for-visual-studio-code/)
- Ability to pick a profile when running/debugging
- Improved unit test discoverability

## Upgrade now to experience the new C# extension

Upgrade now to experience the enhanced capabilities of the newly available C# extension, a key component of C# Dev Kit. This updated open source extension prioritizes performance and reliability, helping you write efficient and robust code. What's new? This update brings faster tooling, improved functionality, and superior stability when used in conjunction with C# Dev Kit.

![C# language server support](VS-Code-CSharp-GTD.gif)

While our latest update has made considerable strides in boosting performance and reliability, our journey of improvements continues. For a detailed understanding of the currently supported features, we invite you to explore the [documentation](https://code.visualstudio.com/docs/csharp/refactoring). Additionally, to stay updated with our development plans and upcoming features, feel free to check out the [feature backlog](https://github.com/dotnet/vscode-csharp/issues/5736). We recognize that the updated C# extension doesn’t have full parity with the OmniSharp version. If you need one of these features before we can get to it, you can switch back to OmniSharp by following these [instructions](https://github.com/dotnet/vscode-csharp/#how-to-use-omnisharp). Note: You must uninstall or disable C# Dev Kit when using OmniSharp.

## Let us know what you think!

Your input and support are vital to us in this ongoing journey of enhancement. As we regularly update C# Dev Kit and its features, we encourage you to provide feedback so we can continuously improve and deliver the best possible experience. Download it today from the [Marketplace](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csdevkit) or install it directly from the extension gallery in Visual Studio Code. Then share your feedback through VS Code’s **Help** > **Report Issue**. Select whether it’s a bug, feature request, or performance issue on "An Extension" and select "C# Dev Kit" from the list of extensions. Alternatively, you can also provide feedback directly on [GitHub](https://github.com/microsoft/vscode-dotnettools/issues). We appreciate your input and look forward to hearing from you!
