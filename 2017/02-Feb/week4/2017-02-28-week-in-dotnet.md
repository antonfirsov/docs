Tool of the week: OzCode
------------------------

[OzCode](http://o.oz-code.com/features) is a great Visual Studio debugging extension that makes debugging Linq considerably easier. Drill down into expressions, analyze the data set at any spot in a fluent call chain, analyze complex Boolean expressions, predict exceptions, and much, much more.

![Debugging Linq with OzCode](http://o.oz-code.com/Media/Default/ImageGalleries/OzCode.Images/openingDetailedWindow.gif)
