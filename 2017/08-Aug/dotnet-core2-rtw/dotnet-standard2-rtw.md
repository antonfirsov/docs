# Announcing .NET Standard 2.0

The [.NET Standard 2.0 specification](https://github.com/dotnet/standard/blob/master/docs/versions/netstandard2.0.md) is now complete. It is supported in [.NET Core 2.0](https://blogs.msdn.microsoft.com/dotnet/2017/08/14/announcing-net-core-2-0/), in the .NET [Framework 4.6.1 and later versions](https://github.com/Microsoft/dotnet/blob/master/releases/README.md), and in Visual Studio. You can start using .NET Standard 2.0 today.
