## Visual Studio extension of the week: Project File Tools

The [Project File Tools](https://marketplace.visualstudio.com/items?itemName=ms-madsk.ProjectFileTools) Visual Studio extension provides package name and version IntelliSense, tooltips for packages, and more, when editing a `.csproj` file in Visual Studio.

![Package IntelliSense](https://github.com/dotnet/ProjFileTools/raw/master/art/completion-name.png)

The extension just got updated. [Get it from the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=ms-madsk.ProjectFileTools).
