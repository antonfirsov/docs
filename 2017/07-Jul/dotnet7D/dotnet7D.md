# .NET Framework July 2017 Quality Update

You can now install the July 2017 Quality Update for the .NET Framework. It applies to multiple Windows versions.

This update resolves [known issue 4033488](https://support.microsoft.com/en-us/help/4033488/comexception-error-from-wpf-applications-after-the-net-framework-4-7-i). It is recommended on machines that have installed the [July 2017 Preview of Quality Rollup](https://blogs.msdn.microsoft.com/dotnet/2017/07/24/net-framework-july-2017-preview-of-quality-rollup/) or the [May 2017 Preview of Quality Rollup](https://blogs.msdn.microsoft.com/dotnet/2017/05/17/net-framework-may-2017-preview-of-quality-rollup/).

## Quality and Reliability

This release contains the following quality and reliability improvements.

#### WPF

* "COMException" error from WPF applications after the .NET Framework 4.7 is installed on Windows 7 or Windows Server 2008 R2

## Getting the Update

This release is available via Microsoft Update Catalog. 

### Docker Images

Docker images have not been updated for this release.
