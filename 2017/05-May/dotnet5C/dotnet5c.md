# .NET Framework May 2017 Preview of Quality Rollup

Today, we are releasing a new Preview of Quality Rollup for the .NET Framework. 

Preview Quality Rollup releases are recommended for businesses that want to use and/or preview quality improvements as soon as they become available. These same quality improvements will typically be included in the following Security and Quality Rollup.

## Security

This release contains the security changes included in the [NET Framework May 2017 Monthly Rollup](https://blogs.msdn.microsoft.com/dotnet/2017/05/09/net-framework-may-2017-monthly-rollup/).

## Quality and Reliability

This release contains 40 fixes from across the following product areas (number of fixes per area included below):

- ASP.NET (8)
- BCL (2)
- CLR (8)
- Entity Framework (1)
- Networking (1)
- SQL Client (4)
- Windows Forms (1)
- WPF (15)

Updates were made in the following .NET Framework releases. Release notes have been updated (for versions that have release notes). 

- [.NET Framework 4.6.2](https://github.com/Microsoft/dotnet/blob/master/releases/net462/dotnet462-changes.md)  ([diff](https://github.com/Microsoft/dotnet/commit/5b8d85fcf64295c7253e946c43f88f24895e7bd2))
- [.NET Framework 4.6.1](https://github.com/Microsoft/dotnet/blob/master/releases/net461/dotnet461-changes.md) ([diff](https://github.com/Microsoft/dotnet/commit/27ce328c067722ae0b5c5f9a2ed3449e4f487acb))
- [.NET Framework 4.6](https://github.com/Microsoft/dotnet/blob/master/releases/net46/dotnet46-changes.md) ([diff](https://github.com/Microsoft/dotnet/commit/7b531eca6e4f7b9c30589439048477f4d009237c))
- .NET Framework 4.5.2
- .NET Framework 3.5

Note: The .NET Framework 4.7 and Windows 10 were previously updated for these changes (including the [May 2017 Quality Rollup](https://blogs.msdn.microsoft.com/dotnet/2017/05/09/net-framework-may-2017-monthly-rollup/)). A small number of fixes were not included and will be part of the next Quality Rollup release.

## Getting the Update

The Security and Quality Rollup is available via Windows Update, Windows Server Update Services and Microsoft Update Catalog. 

### Docker Images

The [Windows ServerCore](https://hub.docker.com/r/microsoft/windowsservercore/) and [.NET Framework](https://hub.docker.com/r/microsoft/dotnet-framework/) images have not been updated for this release.
