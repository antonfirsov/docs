.NET and Docker
===============

Almost everyone we talk to these days is either using Docker actively or planning their adoption of containers in their environment. Microsoft and Docker have been working together so that you'll have a great experience using Docker with .NET apps. The Windows team recently released Windows Server 2016 and updates to Windows 10 that enable Windows containers. You can now use .NET Framework with Windows Server Core containers and .NET Core with Nano Server and Linux. That gives you a lot of choice in the way you build and containerize your .NET apps.

Why Containers?
---------------

There are multiple reasons why developers have been moving to containers to both model, package and distribute their apps.

- **Consistent:** Containers include the application and all of its dependencies. It executes the same code, regardless of computer, environment or cloud.
- **Lightweight:** Containers start instantly and use minimal amount of RAM by using a minimal abstraction over the operating system and sharing common resources across containers.
- **Sharing:** Containers are easy to share across via DockerHub and/or private Docker registries.

Those are not the only reasons or benefits of containers, just the key ones and the easiest the understand.



Containers and containerization are an important trend in our industry.
