December 2016 Updates for .NET Core 1.0
============================

Today, we are releasing a new set of reliability and quality updates for .NET Core 1.0. This month's update is our second [Long Term Support (LTS)](https://blogs.msdn.microsoft.com/dotnet/2016/07/26/net-support-and-versioning/) update and includes updated versions of multiple packages in .NET Core, ASP.NET Core and Entity Framework Core. We recommend everyone moves to this update immediately.

## How to obtain the updates:

* Download and install the [.NET Core version 1.0.3 Runtime or SDK](https://www.microsoft.com/net/download/core/#/runtime)
* Update dependencies in your applications to the latest patch version for 1.0.

## .NET Core 1.0.3 fixes

For more information on the change, please see the [.NET Core 1.0.3 release notes](https://github.com/aspnet/Home/releases/tag/1.0.3).

Debugging
* Visual Studio Remote Debugger with CoreCLR executables on Nano server does not work. [7316](https://github.com/dotnet/coreclr/issues/7316)
* Generate symbol packages for CoreCLR binaries. [5832](https://github.com/dotnet/coreclr/issues/5832)

WinHttpHandler Fixes:
* Nonstandard HTTP authentication responses. [11452](https://github.com/dotnet/corefx/issues/11452), [11456](https://github.com/dotnet/corefx/issues/11456)
* Basic authentication with default credentials. [11266](https://github.com/dotnet/corefx/issues/11266)
* Uri escaping for HTTP requests. [11156](https://github.com/dotnet/corefx/issues/11156)
* WinHttpRequestState objects leak during HTTP resends. [11693](https://github.com/dotnet/corefx/issues/11693)

### ASP.NET Core Fixes:
* Exception page showing only method names in the call stack. [335](https://github.com/aspnet/Diagnostics/issues/335)
* ActionResults returned from controller actions rendered as JSON, instead of executed. [5344](https://github.com/aspnet/Mvc/issues/5344)
* Html.ValidationSummary helper throwing exception when model binding a collection. [5157](https://github.com/aspnet/Mvc/issues/5157)
* WebHost.Run() completes before ApplicationStopping. [873](https://github.com/aspnet/Hosting/issues/873)
* AntiForgeryValidation attribute conflict with CookieAuthenticationEvents OnRedirectToLogin event handler. [1009](https://github.com/aspnet/Security/issues/1009)
* UvException (Error -4047 EPIPE broken pipe) timing out HTTP requests. [1208](https://github.com/aspnet/KestrelHttpServer/issues/1208), [1207](https://github.com/aspnet/KestrelHttpServer/pull/1207)
* UserSecrets causes design-time tools to crash. [543](https://github.com/aspnet/Configuration/issues/543)

### Entity Framework Core Fixes:
* Query: Regression: GroupBy multiple keys throws exception in 1.0.1. [6620](https://github.com/aspnet/EntityFramework/issues/6620)
* Select with Ternary Operator/CASE-WHEN Server Side Evaluation. [6598](https://github.com/aspnet/EntityFramework/issues/6598)
* Query: Including a collection doesn't close the connection. [6581](https://github.com/aspnet/EntityFramework/issues/6581)
* Query: Take() with Include() generates incorrect SQL. [6530](https://github.com/aspnet/EntityFramework/issues/6530)
* Query: Include() for related collections are dropped when use Skip(). [6492](https://github.com/aspnet/EntityFramework/issues/6492)
* Query: Port Include() performance improvement to 1.0.2. [6760](https://github.com/aspnet/EntityFramework/issues/6760)
* Tools: Better ConfigureDesignTimeServices entry point. [5617](https://github.com/aspnet/EntityFramework/issues/5617)
* Query: Entities not being released due to leak in query caching. [6737](https://github.com/aspnet/EntityFramework/issues/6737)

If you are having trouble, we want to know about it. Please report issues on [GitHub issue - 391](https://github.com/dotnet/core/issues/391).

Thanks to everyone who reported issues and contributed!
