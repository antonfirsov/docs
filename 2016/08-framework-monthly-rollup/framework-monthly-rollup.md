# Introducing the .NET Framework Security and Quality Rollup
Enjoy a more predictable and cohesive experience for .NET Framework updates with the new .NET Framework Security and Quality Rollup! The .NET Framework Security and Quality Rollup is a simplified model for providing reliability and security updates to [supported releases](https://support.microsoft.com/en-us/gp/framework_faq) of the .NET Framework. This change is being made to align with the recent update changes that the Windows team has [announced](xxx) and will follow the same monthly release cadence. The Security and Quality Rollup will be available for Windows Vista SP2, Windows 7 SP1, Windows 8.1, Windows Server 2008 R2, Windows Server 2012 and Windows Server 2012 R2.

The Security and Quality Rollup for .NET Framework is a single monthly update that will contain a cumulative set of security and reliability fixes for all versions of the .NET Framework. When you install the monthly rollup, it will only update the version(s) of the .NET Framework that are already installed on your computer. It will not automatically upgrade the base version of the .NET Framework that is installed.

Beginning October 2016, you will be able to download the Security and Quality Rollup for .NET Framework via Windows Update, Windows Server Update Services or the Microsoft Update Catalog. Additionally, each month a security-only release will be available from the Microsoft Update Catalog and Windows Server Update Services.

##.NET Framework Servicing FAQs
###I usually get targeted Hotfix/Reliability rollups from the Download Center, where do I receive these updates from going forward? 
The reliability fixes included in the Hotfix/Reliability rollups will now be included in the Security and Quality Rollup for .NET Framework and offered through Windows Update. 

###How can I get the Security and Quality Update for .NET Framework?
You can download and install the Security and Quality Rollup for .NET Framework via Windows Update, Windows Server Update Services or Catalog. The Security and Quality Rollup for .NET Framework will be available on the same day as the Windows update. 

###When do we start receiving the Security and Quality Update for .NET Framework?
The new Security and Quality Rollup for .NET Framework model begins in October 2016.  

###Why is the .NET Framework changing the update model?
By consolidating into a single monthly update, you will only have to install one package to be up to date with all security and reliability fixes. The update will contain fixes for all versions of the .NET Framework that are currently installed on your computer. 

###Can I opt out of receiving the Security and Quality Rollup for .NET Framework?
By choosing not to install the Security and Quality Rollup for .NET Framework, your computer may be vulnerable to the documented security issues that the  resolves. If you are receiving updates from WSUS or Catalog, you can select an update that contains only the Security Updates for the current month. 

###Do I need to install previous versions of the Security and Quality Rollup for .NET Framework if I miss a month?
You do not need to install previous versions of the Security and Quality Rollup for .NET Framework as the latest one will contain the fixes included in all previous versions. 

###Why is .NET Framework changing the update model?
The new Security and Quality Rollup for .NET Framework allows all customers to be up to date with all Security and Reliability fixes. This model minimizes disruption, reduces fragmentation of the fixes and also provides a cohesive experience to all our .NET Framework customers.

###Will the Security and Quality Rollup for .NET Framework apply fixes to all the .NET Framework versions on my machine? 
‎Yes, the Security and Quality Rollup for .NET Framework will deliver applicable fixes to all versions of .NET Framework on the machine. Updates that are applied will be listed in ‘Add Remove Programs’. 

###Will I be forced to update to a newer version of the framework?
The Security and Quality Rollup for .NET Framework will not upgrade your base Framework version to a newer version. 

 ###What is the estimated size of the Security and Quality Rollup for .NET Framework?
 The Security and Quality Rollup for .NET Framework will be roughly 60MB.

###Can I uninstall the Security and Quality Rollup for .NET Framework?
You can uninstall the Security and Quality Rollup for .NET Framework via the Add Remove Programs panel. You can refer to the .NET Bulletin for the list of KBs each Rollup installed in a particular month.
