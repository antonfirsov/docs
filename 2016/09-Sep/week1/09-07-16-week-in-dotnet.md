Tool of the week: Shaderlab VS
------------------------------

[Shaders](https://en.wikipedia.org/wiki/Shader) are extremely important to game developers, but as they mostly run on graphics cards, they can be challenging to work with. [Shaderlab VS](https://github.com/wudixiaop/ShaderlabVS) provides much welcome features for Unity developers, with syntax highlighting, tooltips, and code completion for shader code.

![Shader code completion](https://github.com/wudixiaop/ShaderlabVS/raw/master/img/CodeCompletion.PNG)

Resource of the week: Awesome Domain-Driven Design
--------------------------------------------------

[Awesome Domain-Driven Design](https://github.com/heynickc/awesome-ddd) is a treasure trove of links about DDD, CQRS, event sourcing, and event storming. In there, you'll find blog posts, podcasts, user groups, courses, books, samples, and mailing-lists. It's curated, and managed as a GitHub repository, so you can contribute.
