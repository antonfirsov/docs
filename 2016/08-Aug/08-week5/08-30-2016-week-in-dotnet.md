Package of the week: F# Data
----------------------------

The [F# Data](http://fsharp.github.io/FSharp.Data/) library takes full advantage of F# type providers to help you read data from various providers such as CSV, or remote JSON or XML APIs.

![Getting IntelliSense on data from a remote API](http://fsharp.github.io/FSharp.Data/images/start.png)

Tool of the week: NDepend
-------------------------

[NDepend](http://www.ndepend.com/) is one of the best ways to find architectural issues in a code base. It will identify problematic coupling and cycles in your dependency structure, and it will enable you to query code using LINQ queries.

![Querying source code using LINQ](http://www.ndepend.com/assets/img/apps/rule.png)
