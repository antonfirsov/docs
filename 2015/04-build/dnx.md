DNX App-Model
=============

The [.NET Environment (DNX)](https://github.com/aspnet/dnx) is a new app-model that works with .NET Core, .NET Framework and Mono. App-model != GUI FX, but defines the fundamentals of how your app functions. For .NET Core, DNX also includes acquisition.

DNX started life in the ASP.NET 5 project, but is now a general .NET Core concept and facility. DNX has gone through several renames over the past few months (was called 'KRE' before), but we'll skip that part.

There are several pieces to DNX, some of which have existed in the .NET Framework and others that new new. The team has been using DNX as the easy way to both acquire and use .NET Core. It's great to use, particularly for the scenario where you SSH into a terminal on Linux.
